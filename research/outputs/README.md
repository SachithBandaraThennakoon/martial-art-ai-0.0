# Generated research outputs

The notebooks create one timestamped run directory under:

- `acp_stgat/`
- `phase_classifier/`
- `system/`
- `llm/`

Each final run should contain configuration, hashes, per-run and aggregate
metrics, per-sample predictions, plots, checkpoint, ONNX export, parity results,
latency results, and the executed notebook. Do not manually edit measured output.
