# Combat Cognition supplementary appendices

This directory contains the publication-ready supplementary evidence referenced
by the independent study report. The report remains self-contained; these files
provide reproducibility details, audit records and anonymized interface evidence.

## Repository link

https://github.com/SachithBandaraThennakoon/martial-art-ai/tree/main/research/Appendix

## Structure

- `A1-Architecture-and-Implementation/` — architecture and component-evidence records.
- `A2-ACP-STGAT-Reproducibility/` — ACP-STGAT result interpretation and per-run metrics.
- `A3-Phase-Classifier-Reproducibility/` — generated-bootstrap phase-classifier interpretation and metrics.
- `A4-System-Interface-and-Functional-Evidence/` — anonymized, descriptively named interface screenshots.
- `A5-P001-Protocol-and-Curated-Evidence/` — expert self-validation record for the selected practice case.
- `A6-Software-Verification/` — consolidated software-verification evidence.
- `A7-Database-Export-and-Failure-Evidence/` — curated export interpretation and retained inconsistency.
- `A8-Literature-and-Claim-Audit/` — verified literature matrix and claim reconciliation.
- `A9-Evaluation-Actions-and-Evidence-Locks/` — closed and bounded evaluation actions.

## Evidence boundaries

- Participant P001 is the researcher/developer/martial-arts expert.
- The empirical case is jab-only and uses one laptop camera.
- Interface screenshots establish displayed states and functional pathways; they
  do not independently establish accuracy, effectiveness or generalizability.
- Generated phase data are not real-human accuracy evidence.
- Original videos, raw identifying screenshots, credentials and raw landmark
  tapes are excluded from this public package.
- No operational LLM is claimed.
